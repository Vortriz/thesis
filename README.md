## QGML

Simulations in Julia

- The notebook to run is [main.jl](notebooks/main.jl)
- The main Quantum Generative Machine Learning (QGML) module is present at [`src`](src/). Additionally, [`CUDA.jl`](ext/QGMLCUDAExt.jl) and [`TensorBoardLogger.jl`](ext/QGMLTensorBoardLoggerExt.jl) extensions are available.
